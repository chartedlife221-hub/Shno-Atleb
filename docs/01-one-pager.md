# شنو أطلب؟ / Shno Atleb — One-Pager

**Tagline:** The exact order to get in Kuwait.
**Pitch:** Don't guess. Order Kuwait's best-selling coffee.

| | |
|---|---|
| **Problem** | Kuwait has a dense, daily coffee culture. People hear about famous drinks ("iced coffee with 3 scoops of white", "iced vanilla Americano") but don't know the exact name or what to say at the counter. Menus are overwhelming; every café claims to be the best. |
| **Solution** | One place showing only the most-ordered items: exact order name, café, area, price (KWD), photo, and a one-line reason. |
| **Differentiator** | "The exact order." Not reviews, not a café directory. |
| **Positioning** | Curated best-seller discovery. **Not** a review platform, café directory, or delivery app. |
| **Audience** | Primary: 18–35 coffee drinkers in Kuwait who discover places via Instagram/TikTok (mobile, Arabic-first, often bilingual). Secondary: newcomers/expats, tourists, people ordering for a group or a gift. |
| **Why now** | Short-form video already drives café discovery in Kuwait; the question "what should I order?" has no dedicated, trusted answer; low build cost (landing page + spreadsheet) makes fast validation possible. |
| **Voice** | Local, conversational Kuwaiti Arabic first, English second. |
| **Trust rules** | Never say "official best seller." Use "Most-ordered pick," "Local favorite," "Staff recommendation," "Cult favorite." No implied brand partnership. Every item has a source and a verification date. |
| **MVP** | Landing page, 20–30 curated items, filters (area, café, type, price), submit-a-best-seller form, waitlist. Target: 3–4 weeks. |
| **Roadmap** | P2 moderated photo-first reviews → P3 personalization + "near me" app → P4 café B2B insights. |
| **Revenue (later)** | Labeled featured placements, delivery-app affiliate links, sponsored "new best seller" drops, premium guides, café insights. |
| **v1 success metrics** | Waitlist signups, user submissions, IG/TikTok saves + shares, repeat visits, filter usage by area/category. |
